# 律师文风工坊

用自己的审定稿生成团队专属的写作 Skill。它学习律师怎样起笔、组织证据、拆分主备位和收束段落。生成的 Skill 可单独安装，也可以交给诉讼文书写作流程使用。

## 开始使用

1. 将本仓库放入 Codex 能读取的工作区。在新对话中指定本仓库的 [SKILL.md](SKILL.md)。也可以在仓库的上一级目录执行 `mkdir -p "$HOME/.agents/skills"` 和 `cp -R legal-voice-studio "$HOME/.agents/skills/"`，之后调用 `$legal-voice-studio`。将生成的团队 Skill 整个目录放进同一目录，即可单独调用它。
2. 选择同一位律师或同一审定团队的现有文书。优先选择若干份已确认的审定稿。若有初稿和审定稿，告诉助手哪些属于同一文书、哪版为准。不同团队分别导入。
3. 发送下面的指令。助手会整理可回查的观察，用相同事实做试写，并请你确认哪种写法可以复用。确认后导出一个独立的 Skill 目录。

> 使用律师文风工坊，从我指定的审定稿学习本团队的写法。先标明团队共通规则、各文体差异和待核观察。展示代表性的同内容改写，经我确认后导出到本工作区 `generated/`，Skill 名称为 `my-team-legal-voice`。

在另一个对话指定 `generated/my-team-legal-voice/SKILL.md`，提供一份新的待改写文本和本次写作要求。可单独分享生成后的规则目录。日常使用只需当前稿和适用规则。

收到新的审定稿时，重新打开工坊，提供该文书的初稿、审定稿和上次学习目录。经确认的规则可导出为新版本，原版本可留用。

## 不带材料体验

从 [合成试用](examples/README.md) 开始。示例团队各有一组改稿和另一份审定稿。试用者可以看到怎样区分律师的写法和案内事实，再用一份新材料比较不同画像。

在仓库根目录运行 `python3 -B -m unittest discover -s tests`，可核对两套画像独立导出、输入校验和拒绝覆盖旧版本。

## 运行条件和数据

- 语义归纳、文风应用和审阅由支持 Agent Skills 的助手执行。首版以 Codex 为验证目标。Markdown、TXT 可直接读取，DOCX 和有文本层的 PDF 使用执行环境可用的文档工具。扫描件需要先取得可核实的文字。
- Python 3.9 或以上可运行导出脚本，无需安装第三方库。已有经审核的规则 JSON 可以直接用 [导出命令](references/profile-format.md) 生成 Skill。
- 工作区用来放样本和审核记录。生成目录仅含抽象规则、合成例句及运行说明。模型如何处理文本取决于试用者所选的运行环境。

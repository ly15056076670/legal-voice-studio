# 从律师样本生成团队文风

## 1. 确定样本的作者、读者和用途

以团队或审定人为一个画像单位。使用用户指定的稿件或目录。从文书类型、受众、作者或审定团队、版本、是否正式审定、是否为同一事项记录每份材料。文件名里的「终稿」「定稿」、Word 修订作者可提供线索；实际审定或提交以可核的记录或用户说明为准。无法确定时把该稿标为待核。一个人经他人改定的稿件可作为该团队审定写法的证据，个人归属待确认。

终稿可以支持稳定写法，成对稿件还能说明修改动作。过程稿单独出现时只供识别可能的组织方式，明确修改前后关系后才推断具体改法。法院裁判、对方文书和固定模板分别用于核对证据归属、对方表达和格式要求。一个事项的多个稿次、多个同类当事人的近似文书只增加一份独立支持。

用可用的本地阅读能力打开 DOCX、TXT、Markdown 和可读 PDF。DOCX 保持标题、正文、表格中的必要语句和位置；审阅修订标记或批注时分别说明其来源。PDF 保留原印页及物理页的对应关系，扫描件先核图像和文字可读性。读取不全就列出缺页、缺段及受影响的观察。样本角色、位置和读取质量记入团队的本地台账。

## 2. 从全体获准样本归纳可执行写法

逐份分析段落承担的作用。抓住结论放在何处、如何从证据到判断、何时使用原判短引、如何列出独立争点，以及何时用备位或收束。把各文书放在其读者和程序任务内理解。先区分格式或规范要求、团队共通写法和某一文体的特定写法；共通规则须有相应的跨文体材料或律师明确认可。语料不足时给出审慎画像，标明哪些文体尚缺支持。

有版本链时，先对齐同一事项的标题、段落、证据、请求和改后去向，再比较词句。一份稿件调整证据、案情、责任、承诺、请求或法律立场时，把变化记在原任务。仅抽取它能支持的组织动作。删除无原因的段落时保留观察，先看是否搬移到别处或是否仅因这次取舍。

比对 DOCX、TXT 或 Markdown 时，可从本 Skill 根目录用 `python3 scripts/align_revisions.py PROCESS FINAL` 定位变化。默认输出位置及差异类型。确需展示对照片段时，可以在私有工作区加 `--include-text`。依据原文核对差分中的否定、推断、责任主体以及备位条件。

每条规则的表达至少能让下一次写作者知道何时使用、如何下笔、哪类含义不能改动以及适用边界。例如，对方用签收推认验收时，可先说明文件只记录签收，再指出验收条件在何处缺证；如果另有验收记录，按全套证据核对。该例给出可迁移的动作，不假定任何真实案件发生过此事。

从不同事项找重复动作和反例。比如，部分审定稿把结论置于标题，却在复杂文书开头集中交代程序和争点。画像应说明什么场景先铺垫、什么场景首句下判断。遇到矛盾优先收窄触发条件或分文体，孤立偏好留待核。可以统计标题长度、短句比例或常用递进词来找候选；以语义和原文上下文判断写法。

## 3. 打包前验证并交付

优先用一份未参与归纳的材料验证。给普通写法和画像写法同一份事实、当前立场、原话、来源和范围。逐段核对程序角色、证据证明程度、正反命题、数字、时间、引用原字与页码、请求及承诺。随后记录实际变化，例如团队更常把裁判已认定的事实放在证据段前，或更常把备位前提写进标题。容易改变意义的地方用反例检验。

将可执行的共通规则和当前有证据支持的文体规则保存为 [画像 JSON](profile-format.md)。合成例句在两版使用相同的虚构事实，可展示不同的起笔和论证次序。把真案内容、文件路径、批注原文、案号、金额及来源清单留在团队工作区。待核规则存入台账。导出包只使用有效的抽象规则和合成例句。在另一会话只带导出的目录和新任务试写，检查无需生成器或历史材料仍可调用。真实测试、合成测试和未验证项分别向用户说明。

## 4. 根据新增审定稿更新

跨会话学习时，把记录落在同一团队的工作目录。沿用用户已有的文件命名。新目录可用 `learning-log.md`、`profiles/1.0.0.json` 和 `generated/1.0.0/<id>/`。学习记录保留样本身份与版次、论证动作的前后定位、关联规则、反例、确认结果和当前生效版本。后续用这份记录恢复任务；原件只在需要回查时获取。此前确认过的规则一并参与更新。

确认新稿属于同一团队，并核对来源、文体及前稿关系。按任务与版本去重。读取已有画像、全量获准的历史台账及新增稿件，回查相关原文和反例。与现有规则一致就补证；出现稳定的新条件或边界就修订对应规则；一份稿件的意思变动按本案处理。把新增、细化、撤销或仍待核的规则告诉律师。

保留上一版 JSON、导出目录和本轮变化记录。用新的输出父目录重新导出同一画像；局部核对后再把它用作有效版本。检查已验证的正例和反例，并以新的材料验证实质改写。若新规则退步，可选回上一版目录。明确授权的审定标准和稳定写法可纳入画像，样本里的业务决定继续由本案指示控制。
